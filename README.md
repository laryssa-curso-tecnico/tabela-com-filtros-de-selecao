# Tabela com Filtros de Seleção

A aplicação apresenta uma tabela de informações com filtros de seleção, permitindo visualizar os dados de forma mais organizada e encontrar informações específicas com mais facilidade.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Desenvolvimento

Projeto desenvolvido individualmente, com orientação e apoio do professor.
